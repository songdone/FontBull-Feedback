# FontBull 字牛 · 用户反馈

字牛是飞牛 fnOS 上的字体管理工具，用于管理 NAS 字库、试字、检查缺字和整理项目用字。

本仓库用于收集使用问题和功能建议，**不提供应用源码，也不包含内部开发记录**。

## 提交反馈

- [报告使用问题](https://github.com/songdone/FontBull-Feedback/issues/new?template=bug_report.yml)
- [提出功能建议](https://github.com/songdone/FontBull-Feedback/issues/new?template=feature_request.yml)
- [查看已有反馈](https://github.com/songdone/FontBull-Feedback/issues)

提交前请先搜索已有问题。报告问题时，请说明字牛版本、fnOS 版本、设备架构（x86 或 ARM）、操作步骤，以及实际出现的提示。截图或必要的日志片段有助于定位。

**Issues 公开可见。请勿上传密码、令牌、配对码、分享链接、完整配置或未经许可的字体文件。截图和日志请遮盖私人路径、项目名称及其他个人信息。**

如涉及安全漏洞，请勿公开利用细节；请使用仓库的私密漏洞报告入口（如已启用）。

## 使用说明

- 字体来源与授权信息是核对线索，不是商用授权保证，请以发布方原始许可为准。
- 随包预览可能只包含部分字符，完整试字需可用的本地原字体或主动下载。
- 应用安装和更新以飞牛应用中心提供的版本及说明为准。
